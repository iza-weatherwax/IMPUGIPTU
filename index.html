Escolha a pasta dos processos

Cada processo de impugnação é salvo como um arquivo .json na pasta que você indicar (por exemplo, uma pasta na rede do departamento). As réplicas geradas em Word ficam na subpasta replicas. Nada é enviado para a internet.

Reconectar à pasta “”

Por segurança, o navegador pede uma nova autorização para acessar a pasta a cada vez que o assistente é aberto.

Modo de compatibilidade

Este navegador não permite gravar diretamente em uma pasta. Para salvar os processos automaticamente na pasta escolhida, abra este assistente no Google Chrome ou no Microsoft Edge.

Neste modo, carregue a pasta para ver os processos já existentes. Ao salvar, o arquivo .json é baixado: guarde-o na pasta dos processos (dica: configure o navegador para perguntar onde salvar cada arquivo).
